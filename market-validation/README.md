# 市场验证：中国出海SaaS AI内容营销服务

> 启动日期：2026-06-07
> 验证周期：2周
> 状态：🟡 联络阶段

---

## 背景假设

中国出海SaaS公司普遍存在"产品强、内容弱"的问题。如果为它们提供AI驱动的内容营销服务（案例海报 + 行业洞察文案 + 社媒内容流），它们是否愿意付费？

## 验证方法

1. 找到20家符合条件的中国出海SaaS公司 ✅
2. 分析其内容质量，选出10家内容最差但产品好的 ✅
3. 为每家生成1张黑金风案例图 + 1段案例文案 ✅
4. 联系对方，发送案例物料，观察反应 ⏳
5. 记录回复率，判断市场信号 ⏳
